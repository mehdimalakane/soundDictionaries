An NVDA add-on that enables assigning custom WAV or MP3 audio file playback to specific phrases across all speech dictionaries.

Features

  • Deep Integration: Fully integrated into NVDA's existing dictionary interface:
    • Default Dictionary
    • Voice Dictionary
    • Temporary Dictionary
  • Dual Format Support: Supports both .wav and .mp3 audio files.
  • Automatic Copying: When an audio file is selected, it is safely copied to the installed add-on's sounds/ folder.
  • Preview and Test: Directly play and preview assigned audio files inside the dictionary entry dialog.
  • Flexible Playback:
    • Assign sound only (replaces the spoken phrase with the sound).
    • Assign sound + replacement text (plays the sound and speaks the replacement text).
  • Exact Speech Synchronization: Sound playback is synchronized with speech synthesis and stops immediately when speech is cancelled (e.g. pressing Control).
  • Full Native Persistence: Stored cleanly using standard NVDA dictionary format with zero corruption risks.

How to Use

  1. Open NVDA Menu (NVDA+N) > Preferences > Speech Dictionaries.
  2. Choose Default dictionary, Voice dictionary, or Temporary dictionary.
  3. Press Add (Alt+A) or select an existing entry and press Edit (Alt+E).
  4. In the entry dialog:
    • Enter the Pattern to match.
    • (Optional) Enter the Replacement text. Leave blank if you only want the sound to play.
    • Press Browse... (Alt+B) to select a WAV or MP3 audio file.
    • Press Play sound (Alt+P) to listen to the selected sound.
    • Press Clear sound (Alt+R) if you want to remove an assigned sound.
  5. Click OK to save the entry.

Keyboard Shortcuts in Entry Dialog

  • Alt+P: Pattern field
  • Alt+R: Replacement field
  • Alt+C: Comment field
  • Alt+A: Audio file field
  • Alt+B: Browse for audio file
  • Alt+Y: Play/preview audio file
  • Alt+D: Clear audio file
  • Alt+S: Case sensitive checkbox
  • Alt+T: Type radio box
